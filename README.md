# Enquetes com Taiga UI

Exercícios com a biblioteca Taiga UI em Angular

Atividade de **Interfaces Ricas** (IR) — IFRN.

## Stack

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white) ![Angular](https://img.shields.io/badge/Angular-DD0031?style=for-the-badge&logo=angular&logoColor=white) ![Taiga UI](https://img.shields.io/badge/Taiga_UI-FF7043?style=for-the-badge) ![Less](https://img.shields.io/badge/Less-1D365D?style=for-the-badge&logo=less&logoColor=white)

## Como rodar

```bash
npm install
npm start
```

O app abre em `http://localhost:4200`.
